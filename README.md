# Mac 보안 대시보드

macOS 기본 보안 기능과 ClamAV 백신을 한 화면에서 점검·관리하는 로컬 도구입니다.

## 설치 (앱으로 사용)
- `설치.command` 더블클릭 → 응용 프로그램 폴더에 **Mac 보안 대시보드.app** 이 설치됩니다.
- Launchpad / 응용 프로그램 / Spotlight에서 실행 → 브라우저에 대시보드가 열립니다.
- 종료: 오른쪽 위 **종료** 버튼, 또는 탭을 닫으면 30분 뒤 자동 종료 (검사 중이면 끝날 때까지 유지)
- 다운로드·문서·데스크탑 검사 시 macOS가 접근 허용을 물으면 **허용**하세요. 거부하면 해당 파일은 "검사 못함"으로 표시됩니다.
  홈 전체를 검사하려면 시스템 설정 > 개인정보 보호 및 보안 > **전체 디스크 접근 권한**에 앱(또는 Python)을 추가하세요.
- 자동 실행 항목 탭을 처음 열면 로그인 항목을 읽기 위해 "System Events 제어" 허용을 묻습니다.
- 코드를 고친 뒤에는 `설치.command` 를 다시 실행하면 앱이 업데이트됩니다.
- 제거: `제거.command` 더블클릭 (격리함·기록 삭제 여부를 묻습니다)
- 다른 Mac에 복사해 설치하면 처음 한 번 보안 경고가 뜰 수 있습니다 → `설치.command` 를 오른쪽 클릭 → 열기.

## 설치 없이 실행
- `실행.command` 더블클릭 (종료: 터미널 창 닫기)
- 터미널: `python3 security_dashboard.py` / 상태만 보기: `python3 security_dashboard.py --check`

## 기능
| 탭 | 내용 |
|---|---|
| 개요 | 방화벽·스텔스·Gatekeeper·SIP·FileVault·XProtect·자동 업데이트·ClamAV 점검, 보안 점수 |
| 방화벽 | 켜기/끄기, 스텔스 모드, 전체 차단, 앱별 허용/차단 (관리자 암호 창이 뜸) |
| 바이러스 검사 | ClamAV로 폴더 검사, 바이러스 DB 업데이트, 발견 파일 격리 |
| 앱 서명 검사 | /Applications 앱의 서명·공증 상태 검사 |
| 자동 실행 항목 | LaunchAgents/Daemons의 서명 없음·실행 파일 없음·의심 경로 탐지 |
| 격리함 | 격리 파일 복원 또는 휴지통으로 이동 |

## 참고
- 서버는 `127.0.0.1`에서만 열리고, 요청마다 일회용 토큰을 확인합니다.
- 격리 파일·기록 위치: `~/Library/Application Support/MacSecurityDashboard/`
- 실시간 감시 기능은 없습니다. 주기적으로 검사하고 DB를 업데이트하세요.
