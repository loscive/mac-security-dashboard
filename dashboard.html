앱상태

ClamAV 설치 필요

바이러스 검사에는 무료 오픈소스 백신 ClamAV가 필요합니다. 터미널에서 아래 순서대로 실행하세요.

1) Homebrew 설치 (없는 경우)

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

2) ClamAV 설치

brew install clamav

3) 이 페이지를 새로 고친 뒤 바이러스 DB 업데이트를 누르세요 (설정 파일은 자동으로 만들어집니다).

ClamAV 검사

설치된 앱 서명·공증 검사

/Applications 의 모든 앱을 Gatekeeper(spctl)로 검사해 서명이 깨졌거나 공증되지 않은 앱을 찾습니다.

자동 실행 항목 (LaunchAgents / LaunchDaemons)

악성코드가 재부팅 후에도 살아남기 위해 주로 숨는 곳입니다. 경고가 있는 항목을 확인하세요.

격리함

격리된 파일은 실행 권한이 제거된 채 보관됩니다. 삭제는 휴지통으로 이동하며, 완전 삭제는 휴지통에서 직접 하세요.
